# reshop — инвентарь Dota 2

Одна страница: короткий текст, поиск, фильтры и карточки предметов. С каждой карточки можно перейти в Steam-трейд, в Telegram или в оба места — это настраивается для каждого предмета отдельно.

Админка доступна только по прямому адресу `/admin.html`; ссылок на неё на сайте нет.

## Структура

```
index.html          главная
admin.html          панель
data.json           товары и настройки
assets/css/base.css общие токены, шрифты, кнопки
assets/css/site.css главная
assets/css/admin.css админка
assets/js/core.js   загрузка, нормализация, GitHub API
assets/js/site.js   поиск, фильтры, карточки
assets/js/admin.js  CRUD, публикация, настройки
assets/fonts/       Golos Text
assets/items/       картинки товаров
tools/deploy-github.mjs  загрузка файлов в репозиторий
```

`about.html` оставлен как редирект на главную для старых ссылок.

## Локальный просмотр

```powershell
cd C:\Users\reshot\Desktop\site_dota2
python -m http.server 8000
```

- сайт: `http://localhost:8000/`
- панель: `http://localhost:8000/admin.html`

Пароль по умолчанию — `reshop`. Смените его в админке: **Настройки → Доступ**.

## Что редактируется в админке

### Предметы

- название, герой, слот;
- цена и количество;
- картинка (загрузка или ссылка);
- статус: в наличии / под заказ / продан;
- **действия на карточке**: только Telegram, только трейд или оба;
- своя ссылка трейда и своя ссылка Telegram (если пусто — общие из «Главной»).

Порядок карточек меняется стрелками в списке.

### Главная

- заголовок и текст сверху;
- ссылка «правила сделок» (сейчас заглушка — Telegram; замените на нужную);
- ссылка на инвентарь Steam;
- Telegram и общая ссылка трейда;
- подпись в футере.

### Настройки

- GitHub: владелец, репозиторий, ветка, путь, токен;
- проверка подключения;
- смена пароля;
- экспорт/импорт JSON, загрузка версии с GitHub, сброс локальных правок.

## Публикация

Правки сохраняются в `localStorage` браузера. Чтобы обновить сайт для всех:

1. **Настройки → GitHub** — заполните репозиторий и fine-grained token с правом **Contents: Read and write**.
2. Нажмите **«Опубликовать»**.

Токен хранится только в браузере и не попадает в репозиторий.

Можно публиковать и скриптом:

```powershell
node tools/deploy-github.mjs
```

Скрипт читает токен из `C:\Users\reshot\.reshop-token` или `.reshop-token.txt` (либо из переменной `RESHOP_GITHUB_TOKEN`).

## Важно

- Пароль в админке — клиентская защита, не настоящая серверная авторизация.
- Токен GitHub даёт доступ к содержимому репозитория; не публикуйте его и отзывайте, если он попал в чужие руки.
- Картинки товаров лежат в `assets/items/`; админка загружает новые туда же.
- `data.json` можно править вручную, но безопаснее через админку.
